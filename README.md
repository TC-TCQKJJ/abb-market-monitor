# ABB Market Intelligence Monitor

Real-time competitive intelligence dashboard tracking ABB's competitors in the industrial automation market.

## Features
- **24 live signals** from 4 verified sources (Siemens Press, Drives & Controls, Power Electronics News, Engineering.com)
- **Strategic insights** with quantified threat analysis for each signal
- **ABB IRB-style robot arm** with inverse kinematics — follows your cursor
- Threat sorting, keyword search, competitor newsroom directory
- Single-file HTML, zero dependencies

## Sources
| Source | Type |
|--------|------|
| [Siemens Press](https://press.siemens.com/global/en) | Competitor official |
| [Drives & Controls](https://drivesncontrols.com/) | Industry media |
| [Power Electronics News](https://www.powerelectronicsnews.com/) | Tech media |
| [Engineering.com](https://www.engineering.com/) | Industry media |

## Deployment
Static site — open `index.html` in any browser. Deployed via GitHub Pages.
